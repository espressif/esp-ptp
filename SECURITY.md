# Security Policy

## Supported Versions

ESP-PTP is distributed as an [ESP-IDF component](https://components.espressif.com/) and through the ESP Component Registry.

For the managed ESP-PTP component, users are encouraged to use the latest available release.

## Reporting a Vulnerability

> [!IMPORTANT]
> ESP-PTP is not currently included in the [Espressif Security Bug Bounty Program](https://www.espressif.com/en/solutions/product-security#security-bug-bounty-program). We plan to bring the project under the program as it progresses toward broader availability.
>Until then, responsible vulnerability reports remain highly valued. Espressif may, at its discretion, offer an appropriate reward for significant security disclosures based on factors such as severity, impact, report quality, and novelty.
>These reports will help us further strengthen the platform ahead of its formal inclusion in the Bug Bounty Program.


Please follow the [Espressif Security Incident Response Process](https://www.espressif.com/en/support/documents/advisories) to
report a suspected security vulnerability.

Please **do not create a public GitHub issue, discussion, or pull request** for a security vulnerability.

When reporting an issue related to ESP-PTP, please provide as much
relevant information as possible, including:

- The affected ESP-PTP version or commit
- The ESP-IDF version, if applicable
- The affected SoC or target
- A description of the vulnerability and its potential security impact
- Configuration required to reproduce the issue
- Steps to reproduce the issue
- A proof of concept, logs, or other supporting information, if
  available

If you are unsure whether an issue has security implications, please
report it through the security reporting process rather than disclosing
it publicly.
