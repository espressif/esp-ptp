# ESP-PTP

IEEE 1588-2008 Precision Time Protocol (PTP) daemon for [ESP-IDF](https://github.com/espressif/esp-idf), published through [The ESP Component Registry](https://components.espressif.com/).

The daemon is a port of [NuttX PTPD](https://github.com/apache/nuttx-apps/tree/master/netutils/ptpd) and uses hardware timestamps from the internal Ethernet MAC.
